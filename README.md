# Job Posting Text Classification

A machine learning project for classifying job postings using text-based features and a LinearSVC model.

## Model

* **Model:** LinearSVC
* **Features:** TF-IDF text features
* **Threshold:** -0.09
* **Validation:** Out-of-fold evaluation + untouched test set

## Results

* **OOF Accuracy:** 98.90%
* **Test Accuracy:** 99.41%
* **Test ROC-AUC:** 99.11%
* **Test PR-AUC:** 96.84%

## Tech Stack

Python, Pandas, NumPy, Scikit-learn, TF-IDF, LinearSVC

## Status

Model training, evaluation, threshold selection, and error analysis completed.
